# 画图

## ⚠️ 强制规则（违反=画图失败）

1. **禁止**用 write 工具创建 SVG / 图片文件当"画图"——那只会在微信端发送失败（SVG 附件被拒）。
2. **必须**运行下面脚本，由脚本调用智谱 cogview-4 生成真实图片。

## 流程（一步到位，不要多轮试探）

1. 直接运行脚本（描述用用户原话，润色成有画面感的描述）：
   ```bash
   python3 skills/draw/scripts/draw.py "画面描述"
   ```
2. 脚本输出两行：
   - `URL: <https://...png>` —— **用这个发图**
   - `PATH: <本地路径>`
3. 调用 **message 工具 send**，参数（关键）：
   - `mediaUrl`：**必须是脚本输出的 `URL:` 那一行**（智谱返回的 https 图片地址），
     不能传本地路径，不能传 SVG 路径。
   - `message`：一句简短的话（如"给你画好啦 ✨"）
4. 确认发送成功（工具返回 ok）后，用一句话汇报，不要长篇解释。

## 注意

- 脚本生成约需 10~30 秒，等待输出即可，不要重复运行。
- 脚本输出 `ERROR:` 时，把错误原样告诉用户，建议换个描述再试。
- 图片 URL 有时效（约24小时），每次重新生成，不要复用旧 URL。
- 描述越具体越好（主体、动作、风格、颜色），画出来更接近用户想要的。
